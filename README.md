# ASHEN REQUIEM — IGNITION

브라우저에서 실행하는 1인용 CPU 대전 격투게임입니다. 이미지와 모션 파일은 `assets/`에 포함되어 있습니다. 빌드나 패키지 설치가 필요 없습니다.

## 실행

`index.html`을 Chrome 또는 Edge로 열거나 정적 웹 서버에서 이 폴더를 제공하세요. `index.html`과 `assets/`의 상대 위치를 유지해야 합니다.

## GitHub Pages

저장소의 최상위에 이 폴더의 **내용물**(`index.html`, `assets/`, `.nojekyll`)을 올린 다음 GitHub Pages의 게시 대상을 해당 브랜치의 루트(`/`)로 설정하면 됩니다.

이 폴더를 저장소의 `game/` 하위에 그대로 올리는 경우, 루트 게시를 설정한 뒤 사이트 주소 끝에 `/game/`을 붙여 접속하세요.

## 조작

| 키 | 동작 |
|---|---|
| ← / → | 이동 / 뒤로 가드 |
| ↑ | 점프 / 2단 점프 |
| ↓ | 앉기 / 하단 가드 |
| Shift | 대시 / 공중 대시 |
| A | 약공격 |
| S | 킥 |
| D | 강공격 |
| Z | 필살기 |
| X | 에너지 캔슬 |
| C | 긴급 버스트 |
| V | 초필살기 |
| T | 도발 |
| Esc | 일시정지 |
| R | 연습 모드 초기화 |

뒤 방향을 빠르게 두 번 누르면 백스텝합니다. ↓ → + A/Z로 커맨드 기술을 사용할 수 있습니다. 연습 모드의 동작 확인에서 개별 모션과 느린 재생을 볼 수 있습니다.

## 포함 기능

- 류헤이·셀렌, CPU 아케이드 4스테이지와 최종 보스
- 콤보 피해량, 입력 예약, 캔슬·버스트·초필살기
- 연습 상대 행동 설정, 무제한 게이지, 입력 기록
- 캐릭터별 독립 자세 프레임과 동작 미리보기
- 이 브라우저에 클리어·최고 점수·최고 콤보 기록 저장

기록은 브라우저의 로컬 저장소를 사용하며, 기기나 사이트 주소가 달라지면 공유되지 않습니다. 소리는 첫 클릭 또는 키 입력 후 재생됩니다. 외부 로그인이나 게임 서버는 필요 없습니다.
